# Student Questionnaire Bank

This is the 50-question student bank for the matching algorithm.

Each item should be answered with a 1-10 slider:

- 1 = strongly disagree
- 10 = strongly agree

Question text should be written as a statement, not a free-response prompt.

Weight is a relative scoring weight, where 1 = low, 2 = medium, and 3 = high.
